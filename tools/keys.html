Server keys for Synaptask

Generates two key pairs in this browser with WebCrypto. Nothing is sent anywhere: this page has no network access.

  • Push (VAPID), ECDSA P-256: lets the reminders reach your devices.
  • Work access, RSA-OAEP 3072: when you let Claude into the Work section, the app seals the Work key to this public key; only the server's private half can open it, and only until the time you chose.

1 · Public keys → web/js/config.js

Replace the two lines in CONFIG with these. Public keys are safe to commit.

2 · Private keys → Supabase secrets (never commit these)

Add these lines to supabase/.env (git ignores it) together with the other secrets in the README, run supabase secrets set --env-file supabase/.env, then delete the file. An env file avoids shell quoting problems with the JSON.

Close this tab when done. New push keys mean every device has to turn push on again; new Work-access keys only affect grants made after the change.
